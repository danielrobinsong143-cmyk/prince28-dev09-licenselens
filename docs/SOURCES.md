
# LicenseLens - Data Sources

## Purpose

This document records the external sources used to collect
open-source license information for LicenseLens.

## 1. SPDX License List Data

- Source: https://github.com/spdx/license-list-data
- Data: License identifiers, names, metadata and license texts.
- Formats: JSON, HTML, RDFa, Text and JSON-LD.
- Terms: CC0.
- Usage: Primary source for standardized license information.

## 2. GitHub Choose a License

- Source: https://github.com/github/choosealicense.com
- Data: License metadata, permissions, conditions and limitations.
- Formats: YAML front matter and plain-text license bodies.
- Terms: MIT.
- Usage: Additional reference for license metadata.

## 3. ScanCode Toolkit

- Source: https://github.com/aboutcode-org/scancode-toolkit
- Data: License detection rules, license texts and reference datasets.
- Formats: Plain text, YAML metadata and structured scan outputs.
- Terms: CC-BY-4.0.
- Usage: Additional reference for license identification.

## Data Collection Notes

- Preserve original source URLs.
- Record the source and version of collected data.
- Preserve copyright notices and required attribution.
- Check individual file licensing where applicable.
- Do not assume every file in a repository has the same license.
- Review applicable terms before redistribution.
